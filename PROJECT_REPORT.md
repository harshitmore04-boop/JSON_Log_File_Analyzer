# MINI PROJECT REPORT
## JSON-Based Log File Analyzer

### 1. Introduction
A log file stores records of events that happen while a computer program is running. These records can include normal activities, warnings, and errors. When a program creates many log entries, checking them one by one can take time. This project uses Python to read log entries stored in JSON format and display a useful summary.

### 2. Problem Statement
Manually reading application logs makes it difficult to quickly identify errors and understand how many warnings or informational events occurred. A simple tool is needed to organize, search, and summarize these records.

### 3. Objectives
- Read log records from a JSON file.
- Display all available log entries.
- Count INFO, WARNING, and ERROR records.
- Filter records by log level.
- Search records using a word or phrase.
- Handle missing or invalid input files.
- Save an analysis summary to a text report.

### 4. Tools and Technologies
- Programming language: Python 3
- Data storage format: JSON
- Editor: VS Code, IDLE, or any text editor
- Libraries: `json`, `os`, and `datetime` from Python's standard library

### 5. System Requirements
**Hardware:** A basic computer capable of running Python.

**Software:** Python 3 and a code editor or terminal.

### 6. Working Method
1. The program opens `logs.json`.
2. Python's `json` module converts the JSON data into Python objects.
3. The program checks whether the file and required fields are valid.
4. The user chooses an operation from the menu.
5. The program displays, counts, filters, or searches the records.
6. The report option saves the summary and error details in `analysis_report.txt`.

### 7. Algorithm
1. Start the program.
2. Open and read the JSON log file.
3. If the file is missing or invalid, display an error and stop.
4. Display the menu.
5. Read the user's choice.
6. Perform the selected operation.
7. Return to the menu unless the user chooses Exit.
8. Stop.

### 8. Main Features
- View all log entries with timestamp, level, and message.
- Calculate totals for INFO, WARNING, ERROR, and other levels.
- Filter entries by INFO, WARNING, or ERROR.
- Search timestamps and messages without case sensitivity.
- Save a report with counts and error details.
- Reload the JSON file after it has been edited.
- Handle missing files, invalid JSON, and incomplete log entries.

### 9. Sample Input
```json
[
  {
    "timestamp": "2026-10-13 10:02:00",
    "level": "ERROR",
    "message": "Database connection failed"
  }
]
```

### 10. Expected Output
With the included sample file, the program reads eight log records. The summary should show:
- Total logs: 8
- Information logs: 3
- Warnings: 2
- Errors: 3
- Other levels: 0

The program also allows the user to view error details and save a text report.

### 11. Advantages
- Easy to use and understand.
- Uses a simple, readable JSON structure.
- Helps locate error records quickly.
- Does not require paid software or third-party libraries.
- Can be extended for larger projects.

### 12. Limitations
- The current version reads one local JSON file.
- The sample log data is manually provided.
- It is a basic analyzer and does not automatically monitor a live server.

### 13. Future Scope
The project can be extended to read multiple files, filter by date range, create charts, export CSV reports, and analyze logs generated by a live application.

### 14. Conclusion
The JSON-Based Log File Analyzer demonstrates the use of Python file handling, JSON parsing, lists, dictionaries, loops, conditions, functions, and exception handling. It provides a simple way to review log records, identify errors, and generate a summary report. The project meets the objective of building a useful beginner-level Python application.
